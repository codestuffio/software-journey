# Security

This project is an early local development scaffold. It does not yet accept repositories or call AI providers.

Do not post secrets, private source, or exploit details in a public issue. Once the GitHub repository exists, use its private vulnerability reporting feature if enabled. A dedicated reporting contact has not been configured yet.

Repository ingestion must treat filenames, symlinks, Git configuration, source text, and documentation as untrusted input. It must not run analyzed code or repository hooks. The first ingestion specification includes resource limits and path containment checks.
