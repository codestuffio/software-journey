# Knowledge generation

This package provides bounded, snapshot-only retrieval and fixed-case retrieval evaluation. It validates repository and snapshot identities, returns cited documentation excerpts, and reports missing or truncated evidence. It does not open a checkout or access a network.

Future tutorial assembly and generated explanations must keep source facts, model inferences, and unknowns distinct. Introduce a provider only after its data-transfer and budget policies are decided. See `docs/product.md`.
