## Why

Teams need to control which releases carry an updated walkthrough and review source sharing before generation.

## What Changes

- Prepare a walkthrough for qualifying published SemVer releases.
- Approve the exact generation request, reuse verified chapters, and attach the completed walkthrough to the selected release.

## Capabilities

- `release-walkthrough`: Release selection, approval, incremental assembly, and publication.

## Impact

Adds a release workflow and extends the planner. PR checks remain previews. No model credentials are needed for planning.
