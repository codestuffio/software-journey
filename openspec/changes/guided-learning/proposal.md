## Why

The explorer and workflow trail expose evidence, but an onboarding developer still needs an ordered path through it. Authored tutorials can provide that path without a model or unreviewed claims.

## What Changes

- Add a revision-pinned tutorial catalog for the existing OpenSpec workflow.
- Add Learning navigation with authored facts and inferences, quoted captured documentation, unknowns, and source citations.
- Add a deterministic citation quality check for tutorial steps.

## Non-goals

No model call, automatic tutorial generation, provider integration, or semantic correctness scoring. Generated explanations remain deferred to R7 and must carry explicit provenance when introduced.

## Observable outcome

A reader with the matching local snapshot and workflow bundle can work through an authored tutorial, inspect the cited captured evidence beside each claim, and see when evidence is unavailable.
